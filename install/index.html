Install and first start

There is no stable release yet. This page describes the packages of the canary builds.

The program inside the packages is still called DDNet (DDNet.exe on Windows). It has not been renamed yet.

Windows

  1. Download KoG-Client-windows.zip and verify it.
  2. Extract the whole zip into a folder. Do not run the program from inside the zip.
  3. Start DDNet.exe.

The program is not code-signed, so Windows SmartScreen may say "Windows protected your PC". Choose "More info", then "Run anyway", but only after you have verified the download.

macOS

  1. Download KoG-Client-macOS.dmg and verify it.
  2. Open the disk image and drag the app into Applications.

The release workflow does not sign or notarise the macOS build. The build files have a signing option, but it is off. macOS will refuse to open the app on the first try. In Finder, Control-click the app and choose "Open", then "Open" again. Or open System Settings, then Privacy & Security, and choose "Open Anyway" after the first attempt. There are no in-app updates on macOS yet: download new versions by hand.

Linux

  1. Download KoG-Client-linux.tar.xz and verify it.
  2. Extract it, open the folder and start ./DDNet.

Only 64-bit x86 is built. The libraries it needs are the same as for DDNet. If it does not start, run it from a terminal and read the message.

Android and iOS

Not available.

Where your data lives

The client uses the DDNet data folder:

  • Windows: %APPDATA%\DDNet
  • macOS: ~/Library/Application Support/DDNet
  • Linux: ~/.local/share/ddnet

Settings are kept in settings_ddnet.cfg and settings_tclient.cfg. So the client shares its settings, skins and maps with an installed DDNet, and with TClient. Back up the folder before the first start if you care about your settings. Programs can sit side by side, but do not run two of them at the same time.

Uninstall

Delete the program folder, or the app on macOS. Your data stays in the data folder above. Delete that folder too if you want to remove your settings; this also removes the settings of a DDNet install that uses the same folder.
