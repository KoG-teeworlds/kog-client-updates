The KoG client is a reference implementation. It exists to demonstrate and test new features that need client integration, such as new network messages and the KoG login. You do not need it to play on KoG: the normal DDNet and Teeworlds clients are fully supported. Builds are for testing and may change or break. Just want to play? →

KoG Client

Try new KoG features in a test version of the game client. You can play KoG without it.

For Windows, macOS and Linux computers. There is no version for phones or tablets.

Install and start

  1. Downloadthe zip file KoG-Client-windows.zip.
  2. Extract itRight-click, "Extract All", pick a folder. Do not start the program from inside the zip.
  3. Start itDouble-click KoG-Client.exe.

"Windows protected your PC"? That is normal: the program is not signed with a certificate Microsoft knows. If you got the file from this page, click "More info", then "Run anyway".

  1. Downloadthe disk image KoG-Client-macOS.dmg.
  2. Open itand drag KoG-Client onto Applications.
  3. Start itThe first time macOS refuses: hold Control, click the app, choose "Open", then "Open" again.

Apple Silicon Macs only. The disk image is built for Apple Silicon (M-series) Macs. There is no build for Intel Macs.

"macOS cannot check the app"? That is normal: Apple has not signed or checked it. Or open System Settings, Privacy & Security, and click "Open Anyway" after the first try. Only do this if you got the file from this page.

  1. Downloadthe archive KoG-Client-linux.tar.xz.
  2. Extract itWith your file manager, or tar -xf KoG-Client-linux.tar.xz.
  3. Start itOpen the new folder and run ./KoG-Client.

Only 64-bit x86 computers are supported. If it does not start, run it in a terminal and read the message. It needs the same libraries as DDNet.

Good to know
  • The client keeps its own settings and does not touch those of DDNet. Where they are: see the FAQ.
  • To reuse your DDNet settings, copy settings_ddnet.cfg over by hand.
  • To remove the client, delete the program folder (on macOS the app). Your settings stay behind in their folder; delete that too if you like.

Is it safe?

Check it instead of trusting us. The code is open, the files are built by public GitHub workflows, and every download can be compared with a signed list. Still, this is a new project run by volunteers. Nobody outside it has reviewed it, and it comes without a warranty. If you are unsure, do not use it.

Run this in the folder of the file you downloaded. It compares the file with the SHA-256 in the list on client.kog.tw (the canary channel).

$m = Invoke-RestMethod https://client.kog.tw/canary/update.json
$want = ($m.packages | Where-Object name -eq 'KoG-Client-windows.zip').sha256
$have = (Get-FileHash .\KoG-Client-windows.zip -Algorithm SHA256).Hash
if ($have -eq $want) { 'OK: the file matches the list' } else { 'DIFFERENT: do not open the file' }
echo "$(curl -fsSL https://client.kog.tw/canary/update.json | grep -A1 '"KoG-Client-macOS.dmg"' | grep -o '[0-9a-f]\{64\}')  KoG-Client-macOS.dmg" | shasum -a 256 -c
echo "$(curl -fsSL https://client.kog.tw/canary/update.json | grep -A1 '"KoG-Client-linux.tar.xz"' | grep -o '[0-9a-f]\{64\}')  KoG-Client-linux.tar.xz" | sha256sum -c

A match shows that you have the file the list names. It does not show that the list is genuine: for that, check its signature. If a newer build was published after you downloaded, the check fails; download again. All checks, step by step.

Questions

Do I need this to play on KoG?

No. The normal DDNet and Teeworlds clients work on KoG. The rules of KoG apply to every client, and KoG staff decide about bans. If you are not sure that a feature of this client is allowed, ask KoG staff first.

Does it replace my DDNet client?

No. It is a separate program that you can install next to DDNet. Its settings, skins and maps live in their own folder:

  • Windows: %APPDATA%\KoG-Client
  • macOS: ~/Library/Application Support/KoG-Client
  • Linux: ~/.local/share/kog-client
Can I use my KoG account?

Yes, but it is optional, and today it does little. The login is in testing and development builds only. It opens your web browser, where you log in on kog.tw as usual. You never type your password into the game. After that the client keeps a key for this computer in the keychain of your system (on Linux, in a protected file) and forgets the rest.

Game servers do not use this key yet. Proving your account when you join a server is planned, not built.

To log out, use the same place in the client settings. That deletes the key from your computer at once. To also remove this computer from your account, finish the browser step it opens, or remove the device on kog.tw. How it works: Technical: the login.

What data does it send?

The same as the DDNet client: it asks the DDNet servers for the server list and downloads maps and skins you do not have. In addition, it can look for new versions on client.kog.tw, and it talks to kog.tw when you log in. There is no tracking, no statistics and no crash reports. The full list is on the privacy page.

How do I update?

On Windows and Linux the client checks a signed list on client.kog.tw when it starts. It asks before it installs anything. It is new and has had little testing, so if it does not work, come back to this page and download the newest file.

On macOS you update by hand. The macOS app contains the same check, but the signed list has no macOS file, so it never offers an update there. Download the new .dmg from this page.

How do I report a problem?

Open an issue on GitHub. Write which version you have, which system you use and what happened. The client is maintained by volunteers, so please do not expect an answer within a set time. If you found a security problem, report it privately through the vulnerability form instead.

Where is the source code?

On GitHub: KoG-teeworlds/kog-client. It is open source under the zlib licence, like DDNet. The client is based on TClient, which is based on DDNet. More in Technical.

Best effort only. The KoG client is maintained by volunteers, with no warranty and no support guarantee. Use at your own risk.
