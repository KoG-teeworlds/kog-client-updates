KoG Client

An open-source Teeworlds client for King of Gores. A fork of TClient, which is a fork of DDNet.

Best effort only

The KoG client is maintained on a best-effort basis by volunteers. There is no warranty, no support guarantee and no release schedule. It can break, change or disappear without notice. Security fixes are made as time allows.

You do not need this client to play on KoG: stock DDNet clients keep working. If you want guaranteed support or a stable experience, use the official DDNet client.

Use at your own risk.

Unstable builds (canary and dev)

Canary and dev builds are for testers. They can break, and they may need a clean reinstall of the stable version. These channels are still being set up: until a build is published, choosing one shows that nothing is available.

Not sure a download is genuine? Verify it. Windows and macOS show warnings on first start: see the install notes.

What it is

The KoG client starts from TClient 10.9.0, which is based on DDNet 20.1. The KoG changes live in separate files where possible, so upstream changes can still be merged.

What exists today

  • Based on TClient 10.9.0 and DDNet 20.1.
  • Removed from TClient: the ChaiScript scripting engine, chat translation (it sent chat to a third-party service) and a committed Steam library.
  • No contact with TClient's servers: update check, information file and identification message to game servers are gone.
  • The client is built without the server.
  • An update check that verifies an Ed25519 signature on the update manifest, checks every downloaded file against its SHA-256 and restores the old files if an update fails. It stays off until the project's signing key exists and a signed release is published.

In progress, not built yet Planned

  • Login with a KoG account in your browser (OAuth 2.0), so no password is typed in the game.
  • KoG messages between client and server, announced with capabilities.
  • Opt-in client-side network statistics.
  • Update channels: stable, canary and dev.
  • A second signature on releases, made with a hardware key held by the maintainer.
  • Code signing and notarisation for Windows and macOS.

There is no release yet. This list describes the first commits (November 2026) and is updated by hand with each release.

Login Planned

Today the client logs in like any other DDNet client. Account and login instructions are on the KoG website. A browser login for the KoG client, so that no password or code is typed into the game, is planned. It is not built yet.
