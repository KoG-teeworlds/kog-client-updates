The KoG client is a reference implementation. It exists to demonstrate and test new features that need client integration, such as new network messages and the KoG login. You do not need it to play on KoG: the normal DDNet and Teeworlds clients are fully supported. Builds are for testing and may change or break. Just want to play? →

Data and building

Privacy Built

Every host you connect to sees your IP address. The KoG additions are small; the rest is inherited from DDNet and TClient. The plain-language version is on the privacy page; this page is the detailed table.

Retention. The client does not keep a record of these requests: login requests are not logged and the browser link is logged by host only. How long the receiving hosts keep your IP address is up to them; this documentation does not state it. For GitHub, see GitHub's own privacy statement; for the KoG account service, see kog.tw.

What is not there #

  • No telemetry, analytics, advertising or crash uploads.
  • kog_hello and kog_telemetry are off and not implemented: nothing is sent.
  • No chat is sent anywhere except to the game server. TClient's chat translation, which sent chat to a third party, was removed.
  • The client no longer contacts TClient's servers (update check, information file, identification message).

Switching things off #

You wantSet
No update check at allkog_check_updates 0 (also in the settings)
No login codecl_kog_login 0. It is off by default in stable builds.
Log in, but never prove the device to a servercl_kog_auto_login 0 (the default; it sends nothing until the join protocol exists)
Another channelkog_update_channel stable|canary|dev, never set from the network
No skin downloadscl_download_skins 0

Settings are entered in the client's console or in the settings menu, and are saved in the config in the data folder named on the overview.
