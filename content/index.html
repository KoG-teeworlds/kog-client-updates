Install and start

Three steps. The program is called KoG-Client. Pick your system:

  1. Downloadthe zip file KoG-Client-windows.zip.
  2. Extract itRight-click the file, choose "Extract All", and pick a folder. Do not start the program from inside the zip.
  3. Start itOpen the folder and double-click KoG-Client.exe.

Windows says "Windows protected your PC"? That is normal for this client. The program is not signed with a certificate that Microsoft knows, and Windows often warns about programs like that. It does not mean that the file is bad. If you got the file from this page, click "More info", then "Run anyway".

  1. Downloadthe disk image KoG-Client-macOS.dmg.
  2. Open itand drag KoG-Client onto the Applications folder.
  3. Start itfrom Applications. The first time, macOS refuses. Hold Control, click the app, choose "Open", then "Open" again.

macOS says it cannot check the app? That is normal for this client. Apple has not signed or checked it, and macOS blocks apps like this on the first try. Another way: open System Settings, then Privacy & Security, and click "Open Anyway" after the first attempt. Do it only if you got the file from this page.

  1. Downloadthe archive KoG-Client-linux.tar.xz.
  2. Extract itUse your file manager, or run tar -xf KoG-Client-linux.tar.xz.
  3. Start itOpen the new folder and run ./KoG-Client.

Only 64-bit x86 computers are supported. If it does not start, run it in a terminal and read the message. The libraries it needs are the same as for DDNet.

  • Its own settingsThe client keeps its own settings folder and does not touch the one of DDNet. Where it is: see the FAQ.
  • Reuse your DDNet settingsCopy settings_ddnet.cfg over by hand, if you want them in the client.
  • Remove itDelete the program folder (on macOS the app). Your settings stay behind in their folder, and you can delete that too.

Is it safe?

Check it instead of trusting us. The code is open, the files are built by public GitHub workflows, and every download can be checked against a signed list.

Still, this is a new project run by volunteers. Nobody outside the project has reviewed it, and it comes without a warranty. If you are unsure, do not use it.

How to check your download

One of the three checks, with the GitHub CLI. It tells you where the file was built, not that the code is good:

gh attestation verify KoG-Client-linux.tar.xz -R KoG-teeworlds/kog-client

Questions

Do I need this to play on KoG?

No. The normal DDNet and Teeworlds clients work on KoG. The rules of KoG apply to every client, and KoG staff decide about bans. If you are not sure that a feature of this client is allowed, ask KoG staff first.

Does it replace my DDNet client?

No. It is a separate program that you can install next to DDNet. Its settings, skins and maps live in their own folder:

  • Windows: %APPDATA%\KoG-Client
  • macOS: ~/Library/Application Support/KoG-Client
  • Linux: ~/.local/share/kog-client
Can I use my KoG account?

Yes, but it is optional, and today it does little. The login is in testing and development builds only. It opens your web browser, where you log in on kog.tw as usual. You never type your password into the game. After that the client keeps a key for this computer in the keychain of your system (on Linux, in a protected file) and forgets the rest.

Game servers do not use this key yet. Proving your account when you join a server is planned, not built.

To log out, use the same place in the client settings. That deletes the key from your computer at once. To also remove this computer from your account, finish the browser step it opens, or remove the device on kog.tw. How it works: Technical: the login.

What data does it send?

The same as the DDNet client: it asks the DDNet servers for the server list and downloads maps and skins you do not have. In addition, it can look for new versions on client.kog.tw, and it talks to kog.tw when you log in. There is no tracking, no statistics and no crash reports. The full list is on the privacy page.

How do I update?

On Windows and Linux the client checks a signed list on client.kog.tw when it starts. It asks before it installs anything. It is new and has had little testing, so if it does not work, come back to this page and download the newest file.

On macOS you update by hand. The macOS app contains the same check, but the signed list has no macOS file, so it never offers an update there. Download the new .dmg from this page.

How do I report a problem?

Open an issue on GitHub. Write which version you have, which system you use and what happened. The client is maintained by volunteers, so please do not expect an answer within a set time. If you found a security problem, report it privately through the vulnerability form instead.

Where is the source code?

On GitHub: KoG-teeworlds/kog-client. It is open source under the zlib licence, like DDNet. The client is based on TClient, which is based on DDNet. More in Technical.
