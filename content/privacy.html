Privacy

In short: the client sends what the DDNet client sends. On top of that it can look for new versions, and it talks to kog.tw when you log in. It has no tracking, statistics or crash reports. Every host you connect to sees your IP address.

The list below comes from reading the source code (PRIVACY.md), before the first stable release. For the technical view see Technical: what is sent where.

What the KoG client adds

  • Update check. In Windows and Linux builds the client downloads https://client.kog.tw/CHANNEL/update.json and update.json.sig (CHANNEL is canary or dev for today's builds). The site is served by GitHub Pages, so GitHub sees the request: your IP address, the time and the usual request headers. If you accept an update, the files come from GitHub's download servers. The client adds neither your name nor your settings. Turn the check off with kog_check_updates 0.
  • Log in with KoG. Only when you press Log in or Log out, and only in canary and dev builds (cl_kog_login). The client talks to kog.tw (or cl_kog_account_url): the login description, the token exchange, the account name, and the registration or removal of your device. It sends the one-time login code, a device name and the public half of a device key. The device name is "KoG Client" plus your system by default and never your computer's host name unless you type it. The login page itself opens in your browser. See how the login works.
  • No telemetry. The settings kog_telemetry and kog_hello exist for planned features. They are off by default and not implemented: nothing is sent.
  • Game servers see what they see from any DDNet client, plus a client version string that names this client.

This website

This site has no analytics, no cookies, no third-party scripts, fonts or images, and it loads nothing from other sites. It is hosted by GitHub Pages, so GitHub processes the requests to it: see GitHub's privacy statement. The download section fetches the release information from this site only.

You can check the list above yourself: search the source for web addresses with grep -rn "https://" src. If you find a request that is not listed here, please open an issue.
