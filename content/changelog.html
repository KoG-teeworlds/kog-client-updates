Changelog

There is no stable release yet. Release notes will be listed here and on the GitHub releases page.

Before the first release

November 2026

  • Forked from TClient 10.9.0 (DDNet 20.1).
  • Added a notice, a README, contributor files and issue templates.
  • Removed the ChaiScript scripting engine, chat translation and the committed Steam library.
  • Stopped contacting TClient's servers.
  • Added the KoG version identity and a hello stub that does nothing yet.
  • Added an updater that verifies signed update manifests.
  • Added release signing and upstream sync scripts, and build, release, spelling and security-scan workflows on GitHub.
  • The client is built without the server and tools by default.
