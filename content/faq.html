FAQ

Is it safe?
We try to make it checkable, not just trustworthy: the code is open, releases are built by public workflows, updates are signed and downloads can be verified (see Verify your download). But it is a new fork, no release exists yet, it has had no independent review, it is not code-signed and it is maintained by volunteers with no warranty. Read the source, verify what you download and decide for yourself.
Will I get banned for using it?
KoG's rules apply to every client, and KoG staff decide on bans, not this site. The client was built to fit KoG's fair-play rules: the scripting engine and chat translation of TClient were removed. Other TClient features are still there. If you are unsure whether a feature is allowed, ask KoG staff before you use it.
Does it work on 0.7 servers?
We have not tested it. It is based on DDNet 20.1, and DDNet's own client has limited support for 0.7 servers. We have not checked what that means for this client.
Why a separate client?
To have an open-source client for KoG that anyone can read and improve, with signed updates, and later a browser login so that no password is typed into the game. It is not meant to replace DDNet.
Do I need it to play on KoG?
No. Stock DDNet clients keep working on KoG servers.
Does it replace my DDNet install?
No, but it uses the same data folder, so settings, skins and maps are shared. See Install and first start.
Why is the program still called DDNet?
The rename has not been done yet. "KoG Client" is a placeholder name.
How do I report a bug?
Open an issue with the version, your system and what happened. Please do not expect an answer within any time frame. Security problems go through private vulnerability reporting.
Can I contribute?
Yes. See CONTRIBUTING.md. The code is under the zlib licence, like DDNet.
