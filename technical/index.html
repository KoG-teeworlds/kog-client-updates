The KoG client is a reference implementation. It exists to demonstrate and test new features that need client integration, such as new network messages and the KoG login. You do not need it to play on KoG: the normal DDNet and Teeworlds clients are fully supported. Builds are for testing and may change or break. Just want to play? →

Technical documentation

How the KoG client is built, signed and checked, page by page, and what exists today versus what is only planned. Looking for a download? Go to the start page.

Status of these pages. Everything here describes the client only, and was read from the repository KoG-teeworlds/kog-client (its docs/ folder, source and workflows, at the state of 24 November 2026) and from the files published at client.kog.tw. A claim that was not run or tested says so on the page. Anything that is not built is marked Planned.

What it is and is not #

The KoG client is a reference implementation: a working example of features that need new code in the game client. It is a fork of TClient 10.9.0, which is a fork of the DDNet client 20.1. The KoG-specific code lives in separate files (kog_*), so upstream changes can still be merged.

  • Added: a verifying updater, a browser login with a device key, release signing and sync scripts, build and release workflows.
  • Removed from TClient: the ChaiScript scripting engine, chat translation (it sent chat to a third-party service) and a committed Steam library. The client no longer contacts TClient's servers.
  • Not an official release of Teeworlds, DDNet or TClient, and not endorsed by their authors. "KoG Client" is a placeholder name.
  • Not required to play on KoG, and not a stable product: there is no stable release yet.
  • The executable is KoG-Client (KoG-Client.exe, KoG-Client.app). Its data folder is separate from DDNet's: %APPDATA%\KoG-Client, ~/Library/Application Support/KoG-Client, ~/.local/share/kog-client.
